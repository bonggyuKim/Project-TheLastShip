# 통로 구조 재설계안 — 4인 확장 대비 (v1, 제안 단계)

정본 아님. `ship-scale-and-density-v1.md` §0.1/§3.1/§3.5의 확정값에 대한 **추가 제안**이며, PM/사용자 검토 전까지 시공 지시가 아니다.

## 0. 결론

1. **주 통로(조종석-A-엔진실-B-산소실)의 폭·개구부·배플은 안 바꾼다.** 대신 **엔진실을 우회하는 정비 덕트 1개**를 신설한다. 새 구역이 아니라 연결 구조다.
2. **무효화되는 기존 검증값은 0건이다.** 덕트는 기존 통로에 얹는 게 아니라 별도로 추가하는 것이라, `PassageWidth`·`BaffleOffsetT`·`GAP_Z`·`SIMUL_ZONES ≤ 2`·게이지 T5·구역오디오 T3 전부 그대로 유효하다. 대신 **덕트 자체가 새로 검증받아야 한다** — 아래 §4.
3. **구역 수 `3`개는 유지한다.** 사용자 지시의 "구역 수"는 통로 위상의 축이지 `조종석/엔진실/산소실` 동결(§3.2 요청 2-c, 이미 확정)을 재론하는 게 아니라고 해석했다. 다르면 정정 요청 바란다.
4. **"통로가 단순하다"는 지적은 절반만 이 카드 소관이다.** 밀도(잡동사니·배관·조명)는 `CT-11` 몫으로 이미 분리돼 있다(`ship-scale-and-density-v1.md` §0.1 A1/A2/A3 표 하단). 이 문서가 답하는 것은 **위상**(폭/분기/구역)이지 **밀도**가 아니다. 덕트가 "우주선 느낌"에 기여하는 건 위상 차원에서다(§2).

## 1. 왜 지금 문제가 되는가 — 2인에서 안 보이던 것

`concept-draft.md` §9의 4인 확장 게이트 조건은 명시적이다.

> "네 번째 사람이 물건 간섭·동시 구조·**대안 경로**를 만들고 매 항해 역할 교환이 발생해야 한다."

현재 위상은 **대안 경로가 구조적으로 `0`개다.** 조종석에서 산소실로 가는 경로는 항상 `통로A → 엔진실 → 통로B` 하나뿐이고, 두 팀이 어디를 향하든 반드시 같은 두 배플 지점을 지난다.

2인에서는 이게 문제가 안 됐다 — 두 사람이 마주치는 빈도 자체가 낮고, `§3.5`가 이미 "잠깐 비켜서는 정도는 비용이 아니라 짜임"이라고 판정했다. **4인이면 다르다.** 두 팀(§9 "두 팀이 나뉘되 공간을 공유해 서로 영향")이 각자 다른 용무로 같은 병목을 반복 통과하면, 짜임이 아니라 **줄서기**가 된다. 빈도가 다르면 같은 병목도 다른 경험이다.

## 2. 제안 — 엔진실 우회 정비 덕트

```text
                 조종석 ── 통로A ── 엔진실 ── 통로B ── 산소실
                            |                    |
                            └──── 정비 덕트 ─────┘
                        (엔진실 내부를 지나지 않는다)
```

**형태.** 폭 `0.9m` 단일 통행, 허리 높이 파이프·배선 다발이 벽을 채운 저상 구간(웅크림 이동). 통로A·B와 대비되는 폭으로 **"넓은 간선 vs 좁은 정비로"** 대비를 만든다 — 이 대비 자체가 밀도 없이도 "배 안에 여러 층위 구조가 있다"는 우주선감을 준다.

**진입 지점.** 통로A 쪽 끝(개구부 `0` 근처, 조종석 구역 안)과 통로B 쪽 끝(개구부 `3` 근처, 산소실 구역 안). **엔진실 내부에는 진입점을 두지 않는다** — 엔진실에서 작업 중인 승무원의 동선과 안 겹치게 하는 게 목적이다.

**필수 조건 — 꺾어야 한다.** 덕트가 직선이면 통로A 쪽 입구에서 통로B 쪽 입구가 그대로 보이고, 통로A는 조종석 구역·통로B는 산소실 구역이므로(§2.5, `ZoneBoundaryX`) **구역 간 직선 관통 시선**이 그대로 생긴다. 주 통로가 이미 이 문제로 꺾여 있고(§3.5 "꺾인 통로가 판독선을 죽이지 않는다") 배플까지 뒀다. 덕트는 **같은 규칙, 다른 기하**로 풀어야 한다 — 최소 `1`회 직각 꺾임, 별도 배플 불필요(꺾임 자체로 충분, `L`자 이상이면 배플 없이도 관통선이 없다).

**압력/산소 취급.** 덕트는 어느 `ZonePressure` 구역에도 속하지 않는다. 상시 진공(또는 별도 밀폐)으로 두고, **통과 중에는 `SuitOxygen` 예산을 소모한다.** 이게 핵심이다 — 덕트가 주 통로보다 "더 나은 길"이면 항상 그것만 쓰게 되어 주 통로 설계 전체(배플, 게이지, 판독 3단)가 무의미해진다. 산소 비용이 있어야 **"급할 때만 쓰는 진짜 우회로"**가 된다.

## 3. 구체 시나리오 — 4인, 왜 2인에는 없던 상황인가

```text
운석이 엔진실에 충돌. 조종석·산소실 양쪽에서 대응이 필요하다

A1  조종석에서 조종 입력 유지 (hold)
A2  엔진실로 가서 배전반 작업
B1  산소실에서 서리 확인 중
B2  엔진실로 가서 냉각 결합부 작업

A2·B2 가 엔진실 안에 같이 있다 (팀이 나뉘어 있어도 공간은 공유 — §9)

이때 산소실 압력이 갑자기 0.15 밑으로 떨어진다 (전선 사이렌)
B1 은 A1 에게 알려야 한다. 기존 위상이면:

  통로B 진입 → 엔진실 통과(A2·B2 작업 중, 배플 옆 1차선) → 통로A → 조종석
  네 사람이 한 지점(엔진실 배플 두 곳)을 순서대로 다 거친다

덕트가 있으면:

  B1 이 산소실 쪽 덕트 입구로 들어간다 (SuitOxygen 소모 감수)
  엔진실을 거치지 않고 통로A 쪽 출구로 나와 조종석에 바로 알린다
  A2·B2 는 방해받지 않는다
```

**대안 경로가 실제로 결과를 바꾼 지점.** B1이 덕트를 쓸지 말지가 "산소 예산을 얼마나 남겨뒀는가"에 달려 있다 — 방금 산소실에서 진공 작업을 했다면 못 쓴다. **매 항해 역할 교환**(§9 4인 조건의 나머지 절반)은 이 예산 상태가 매번 달라서 자연히 생긴다.

## 4. 새로 검증받아야 하는 것 (무효화가 아니라 신규)

기존 CT-09/CT-10 검증은 **주 통로 기준으로 손상 없음.** 대신 덕트 자체가 다음을 새로 통과해야 한다.

| 항목 | 요구 | 소관 |
|---|---|---|
| 덕트 내부 직선 관통 시선 없음 | `L`자 이상 꺾임으로 `A3` 규칙 충족 | `game-tech-director` |
| 덕트 진입점이 `SIMUL_ZONES ≤ 2`에 안 걸리는지 | 진입점에서 반대쪽 출구·엔진실 내부가 동시에 안 보여야 함 | `game-qa`, T4 확장 |
| 덕트 통과 소요 시간 | `ZONE_TRANSIT 3.5초` 대비 얼마나 걸려야 "급할 때만"이 성립하는지 | `game-balance` |
| 덕트 통과 중 `SuitOxygen` 소모율 | `80초` 예산에서 왕복 몇 회분인지 | `game-balance` |
| 저상 이동(웅크림) 시 `MoveSpeed` 페널티 여부 | 페널티 없으면 그냥 더 빠른 길이 되어 §2 산소 비용 취지가 무너짐 | `game-tech-director` |
| 물건(예: `PatchPlate 1.15m`)이 덕트를 지날 수 있는지 | 폭 `0.9m`면 못 지난다 — **의도된 제한인지 확인 필요** | `game-planning` (미결, §6) |

## 5. 트레이드오프

- **아트 비용 신규 발생.** 덕트는 `CT-11`(통로 밀도, 보류 중)과 무관하게 새 공간이라 별도 키트가 필요하다. 카드 스코프에 넣을지는 PM 판단.
- **탈출 경로가 늘어난다는 것은 `RG-1 (4-b)` 재계산 대상이라는 뜻이다.** 덕트가 최단 탈출로가 되는 경우가 생기면 §5.1(`ship-scale-and-density-v1.md`)의 탈출 시간이 바뀐다. 이번엔 계산 안 했다 — 덕트 소요 시간이 먼저 확정돼야 한다.
- **"급할 때만 쓴다"는 산소 비용 하나로 지켜진다.** 밸런스가 비용을 너무 낮게 잡으면 덕트가 상시 지름길이 되어 주 통로 설계(배플·게이지·판독 3단) 전체가 장식으로 전락한다. 반대로 너무 높으면 아무도 안 써서 §9 4인 게이트 조건을 실질적으로 못 채운다.

## 6. 미결 사항

- **덕트 폭 `0.9m`가 아이템 반입을 막는 것이 의도인지.** 막는 쪽(정비 전용, 순수 이동 우회)과 여는 쪽(`PatchPlate`도 지나가게) 중 하나를 정해야 한다. 기획 판단이 필요하지만 §4의 시간·산소 수치가 먼저 나와야 저울질이 된다 — 이번엔 보류.
- **`RG-1 (4-b)` 탈출 경로 재계산.** §5 트레이드오프 참조. 덕트 시간 확정 후 진행.
- **"통로가 단순하다"는 원 지적 중 밀도분이 이 제안으로 얼마나 해소되는지.** 주 통로 자체의 밀도는 안 건드렸다. `CT-11` 재개 시 사용자 체감 재판정 필요.
- **구역 수 재해석 확인.** §0-3에서 "구역 수"를 통로 위상 축으로 읽었다. PM/사용자가 `조종석/엔진실/산소실` `3`개 동결 자체를 재론하는 뜻이었다면 이 문서는 범위가 좁다 — 확인 요청.

## 7. 용어

- **주 통로**: 기존 조종석-통로A-엔진실-통로B-산소실 직선 위상. `ship-scale-and-density-v1.md`의 정본 그대로.
- **정비 덕트**: 이 문서가 신설 제안하는 엔진실 우회 연결 구조. 구역이 아니다.
- **대안 경로**: `concept-draft.md` §9 4인 게이트 조건의 표현을 그대로 쓴다. "우회로"·"바이패스" 등 다른 말로 안 바꾼다.

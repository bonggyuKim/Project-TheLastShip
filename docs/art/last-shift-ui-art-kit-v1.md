# LAST SHIFT UI 아트 키트 v1

## 방향

UI를 **낡은 우주선의 장난감 계기판**으로 통일한다. 아이보리 외곽선과 짙은 청람 패널이 정보를 묶고, 오렌지·연녹색·시안·황색은 기능색으로만 쓴다. 표면 오염 대신 둥근 모서리, 넓은 외곽선, 큰 픽토그램으로 기존 로우폴리·라운드 챔퍼 언어를 2D에 옮겼다.

색만으로 구분하지 않는다. 정비는 렌치, 자재는 상자, 산소는 탱크와 기포, 식량은 사과처럼 **32px에서도 다른 실루엣**을 갖는다. 도킹은 작은 선체를 양쪽 클램프가 감싸는 굵은 형상으로 교체했다.

## 납품물

- `Assets/DoodleUp/Art/UI/LastShift/icon_gauge_*_base.png`: 비어 있는 상태의 외곽선 아이콘 8종, 128×128
- `icon_gauge_*_fill.png`: 같은 좌표의 컬러 채움 아이콘 8종. base 위에 겹쳐 아이콘 자체를 게이지로 쓴다.
- `panel_9slice.png`: 128×128, Unity border 16px. 로비·튜토리얼·결과·카탈로그의 공용 패널
- `prompt_plate.png`, `keycap.png`: 월드 앵커 프롬프트와 입력 키 표시
- `Tools/art/generate_last_shift_ui_kit.py`: 모든 PNG와 `.meta`를 결정적으로 재생성

| 표면 | 구성 | 우선 정보 |
|---|---|---|

| 도킹 | 도킹 base + fill, 필요하면 오른쪽에 목표 수치 | 현재 진척, 목표선 |

| 선체/거점 배치 | 공용 패널 + 선택 탭에 오렌지 6px 밴드 | 선택 항목, 비용, 배치 가능 여부 |

## UGUI 연결 규격

- 기준 캔버스 1920×1080, `Scale With Screen Size`, match `0.5`.
- 패널 최소 크기 192×96. 9-slice 모서리 16px 아래로 축소하지 않는다.
- 아이콘 HUD 48px, 월드 프롬프트 48px, 결과 칩 32px. 32px 미만 사용 금지.
- base와 fill은 같은 RectTransform에 정확히 겹친다. fill `Image`는 `Type=Filled`, `Fill Method=Vertical`, `Origin=Bottom`으로 두고 `fillAmount`만 변경한다.
- 정상 `#4FD8A0`, 불안정 `#FFDB59`, 위기 `#FF5A4D`; 위기만 1.5Hz 이하 명도 펄스 허용. 색상 교체 없이 알파 점멸하지 않는다.
- 숫자는 항상 채움 바깥 라벨에 둔다. 채움 위 흰 글자는 30% 이하 잔량에서 대비가 무너진다.

## UGUI 연결 상태 (구현 카드 `d73ee4c7`)

`com.unity.ugui` 를 새로 넣었다 — 이 프로젝트에는 캔버스가 한 장도 없었다.

- **키트 참조**: `Assets/DoodleUp/Resources/LastShiftUiKit.asset` 이 16장을 GUID 로 들고 있고, 그림은 이 문서가 약속한 경로에 그대로 남는다. 굽는 곳은 `DoodleUp/LAST SHIFT/UI 아트 키트 굽기` 메뉴(`LastShiftUiKitBuilder`) 하나다.
- **임포트 설정은 코드가 쥔다**: v1 이 손으로 쓴 `.meta` 를 유니티가 못 읽어(`could not be parsed`) **그림이 통째로 무시되고 있었다.** `.meta` 는 이제 guid 만 들고, 스프라이트 여부·9-slice 경계·`FullRect` 메시·`Texture2D` 모양은 빌더가 정한다.
- **9-slice 경계 추가**: 패널 `16`, 프롬프트판 `44/20/24/20`(왼쪽 삼각 표식 보존). **아이콘에는 경계가 없다** — 늘어나지 않고 정사각형으로만 놓인다.
- **게이지에는 가로 막대도 프레임도 없다.** 축 하나가 `icon_gauge_<축>_base`(빈 외곽선)와 `icon_gauge_<축>_fill`(컬러 채움) 두 장으로 오고, 둘이 **같은 사각형에 겹친 채** 채움만 `fillAmount` 로 아래에서 위로 찬다. 위 §"트레이드오프" 가 별도 바를 없앤 결정 그대로다. 임계선·이동선은 채움이 세로로 차오르므로 **가로줄**로 그린다.
- **완전히 UGUI 로 옮긴 것**: 상호작용 프롬프트(판+아이콘+키캡), 계통 게이지 3(추력·전력·열), 도킹 게이지와 이동 필요선, 자원 게이지 4, 개인 예비 산소 게이지, 조준점, 하단 조작줄, **상시 HUD 의 글자 전부**(목표 줄·도킹 시계·지배 문제 줄·배터리·구역 압력 4칸·진단 줄·튜토리얼 띠·F3 디버그 층·방 코드 띠·도면 안내 줄).
- **패널만 9-slice 로 바꾼 것**: 결과 카드, 선체·거점 도면. 도면의 선·면과 로비 접속 화면의 입력칸은 IMGUI 로 남는다 — 전자는 좌표로 그리는 그림이고 후자는 접속 경로 전체 재검증이 걸린다.
- **IMGUI 글자를 옮길 때 글자 크기도 같이 환산해야 한다**(`LastShiftUiTheme.ScreenFontSizeToCanvas`). 자리만 캔버스 단위로 나누고 크기를 그대로 두면, 캔버스가 배율만큼 다시 키울 때 상자는 제자리이고 글자만 커져 4K 에서 넘친다.
- **식량 게이지는 값이 없다.** 식량 계통이 아직 없어 `LastShiftResourceGauges.Food()` 가 `Available=false` 를 돌려주고 줄이 비어 있다. 참고로 `campaign-scale-and-combat-balance-v1.md` 조항 `B-4` 는 산소·식량 재고를 **남은 구간 수**로 세라고 하므로, 구간 재고가 들어오면 그 축은 게이지가 아니라 숫자로 붙어야 한다. 지금 산소 게이지가 재는 것은 재고가 아니라 **서 있는 구역의 압력**이다.
- **자재는 상한이 없다.** 게이지는 `24` 를 한 화면으로 잡은 눈대중이고 정본은 옆 숫자다. 정비여력만 실제 상한(조항 `B-2`, `12`)이 있어 비율이 참이다.

## 트레이드오프와 수동 확인

별도 가로 바를 없애 화면 폭과 시선 이동을 줄였다. 대신 25% 단위의 정밀 비교는 숫자 라벨에 의존한다. Unity에서 실제 UGUI로 연결한 뒤 16:9·16:10·울트라와이드에서 25%/50%/75% 채움이 형상을 훼손하지 않는지, 32px 실루엣과 색각 이상 모드, 밝은 조종석 위 대비를 눈으로 확인해야 한다.

# LAST SHIFT UI 아트 키트 v1

## 방향

UI를 **낡은 우주선의 장난감 계기판**으로 통일한다. 아이보리 외곽선과 짙은 청람 패널이 정보를 묶고, 오렌지·연녹색·시안·황색은 기능색으로만 쓴다. 표면 오염 대신 둥근 모서리, 넓은 외곽선, 큰 픽토그램으로 기존 로우폴리·라운드 챔퍼 언어를 2D에 옮겼다.

색만으로 구분하지 않는다. 정비는 렌치, 자재는 상자, 산소는 탱크와 기포, 식량은 사과처럼 **32px에서도 다른 실루엣**을 갖는다. 도킹은 작은 선체를 양쪽 클램프가 감싸는 굵은 형상으로 교체했다.

## 납품물

- `Assets/DoodleUp/Art/UI/LastShift/icon_gauge_*_base.png`: 비어 있는 상태의 외곽선 아이콘 8종, 128×128
- `icon_gauge_*_fill.png`: 같은 좌표의 컬러 채움 아이콘 8종. base 위에 겹쳐 아이콘 자체를 게이지로 쓴다.
- `panel_9slice.png`: 128×128, Unity border 16px. 로비·튜토리얼·결과·카탈로그의 공용 패널
- `prompt_plate.png`, `keycap.png`: 월드 앵커 프롬프트와 입력 키 표시
- `Tools/art/generate_last_shift_ui_kit.py`: 모든 PNG와 `.meta`를 결정적으로 재생성

## 화면별 적용

| 표면 | 구성 | 우선 정보 |
|---|---|---|
| 상호작용 | `prompt_plate` + `icon_interact` + `keycap` | 대상명, 입력키 |
| 도킹 | 도킹 base + fill, 필요하면 오른쪽에 목표 수치 | 현재 진척, 목표선 |
| 자원 4종 | 자원별 base + fill | 아이콘 자체의 잔량; 숫자는 보조 |
| 결과 | 기존 결과 화면 v1 좌표 유지, `panel_9slice`로 카드 교체 | 판정 → 원인 → 4칸 요약 |
| 선체/거점 배치 | 공용 패널 + 선택 탭에 오렌지 6px 밴드 | 선택 항목, 비용, 배치 가능 여부 |
| 튜토리얼 | 공용 패널 82% 불투명 + keycap | 행동 동사, 키 |
| 로비 | 공용 패널 + 방 코드를 40px 이상 keycap 묶음 | 방 코드, 연결 상태 |
| 하단 조작줄 | 청람 72% 단색 띠, keycap 반복 | 현재 문맥에서 가능한 입력만 |

## UGUI 연결 규격

- 기준 캔버스 1920×1080, `Scale With Screen Size`, match `0.5`.
- 패널 최소 크기 192×96. 9-slice 모서리 16px 아래로 축소하지 않는다.
- 아이콘 HUD 48px, 월드 프롬프트 48px, 결과 칩 32px. 32px 미만 사용 금지.
- base와 fill은 같은 RectTransform에 정확히 겹친다. fill `Image`는 `Type=Filled`, `Fill Method=Vertical`, `Origin=Bottom`으로 두고 `fillAmount`만 변경한다.
- 정상 `#4FD8A0`, 불안정 `#FFDB59`, 위기 `#FF5A4D`; 위기만 1.5Hz 이하 명도 펄스 허용. 색상 교체 없이 알파 점멸하지 않는다.
- 숫자는 항상 채움 바깥 라벨에 둔다. 채움 위 흰 글자는 30% 이하 잔량에서 대비가 무너진다.

## 트레이드오프와 수동 확인

별도 가로 바를 없애 화면 폭과 시선 이동을 줄였다. 대신 25% 단위의 정밀 비교는 숫자 라벨에 의존한다. Unity에서 실제 UGUI로 연결한 뒤 16:9·16:10·울트라와이드에서 25%/50%/75% 채움이 형상을 훼손하지 않는지, 32px 실루엣과 색각 이상 모드, 밝은 조종석 위 대비를 눈으로 확인해야 한다.

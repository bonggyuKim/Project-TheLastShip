# LAST SHIFT 실제 에셋 제작 착수안 (v1)

카드 `e3c1d16b`의 범위는 새 에셋을 한 번에 전부 만드는 것이 아니라, 현재 씬에서 **이미 스타일이 들어간 부분과 여전히 그레이박스인 부분을 분리**하고 다음 제작 순서를 잠그는 것이다. 코드와 절차적 배치는 이번 범위에서 건드리지 않는다.

기준은 `last-shift-art-style-guide-v1.md`의 로우폴리 스타일라이즈드, 밝고 선명한 포스터컬러, 무광 표면, 라운드 챔퍼, 약간 과장된 소품 비례다. 플레이 거리에서는 장식량보다 출입구·상호작용물·방 정체성이 먼저 읽혀야 한다.

## 1. 현재 인벤토리

2026-08-08 저장소 기준으로 프리팹 `100`개, 머티리얼 `87`개가 있다. 프리팹은 드레싱 `90`, 선체 `4`, 루트/아이템/플레이어 `6`개다. 따라서 “전부 기본 큐브”는 구조체에는 맞지만, 소품과 기능색까지 빈 상태는 아니다.

| 생활공간 개인화 | 침대·테이블 등 기능 소품은 있으나 서사 밀도 낮음 | 담요, 머그, 자석 메모, 삐뚤어진 개인 선반처럼 값싼 변주 세트 필요 |

구조체가 차지하는 화면 면적이 가장 크기 때문에 소품 수가 많아도 현재 스크린샷은 그레이박스로 읽힌다. 핵심 결손은 텍스처 양이 아니라 **대면적 표면의 모서리·분할·깊이 정보 부족**이다.

## 2. 제작 우선순위

### P0 — 공통 구조체 키트

먼저 전체 구조체에 텍스처를 덮는 방식은 채택하지 않는다. 이 프로젝트의 스타일은 플랫 컬러와 형태가 중심이라, 단순 타일 텍스처는 큐브 실루엣을 그대로 남기고 노이즈만 늘린다.

첫 제작물은 아래 `8`종 모듈러 키트다.

1. 직선 벽 패널 `2`종(일반/기능 인셋)
2. 바닥 패널 `2`종(일반/격자 인셋)
3. 천장 패널 `1`종
4. 둥근 출입구 프레임 `1`종
5. 모서리 리브 `1`종
6. 바닥 스커트 `1`종

모든 조각은 기존 그레이박스 치수와 문 개구부를 바꾸지 않고 교체 가능한 스킨이어야 한다. 챔퍼는 실루엣에 보이는 폭만 주고, 작은 볼트·스크래치는 넣지 않는다. 한 화면에서 `70%`는 중립 청회색, `20%`는 방 고유색, `10%`만 발광·해저드가 되도록 유지한다.

**첫 적용 구간은 조종석 → 중앙 광장 → 선수 관측실 동선**이다. 첫 진입, 협동 집결, 큰 창이라는 세 장면이 이어져 체감 효과와 리뷰 효율이 가장 높다. 전체 방에 얇게 뿌리기보다 이 동선을 수직 슬라이스로 완성한 뒤 키트를 확장한다.

### P1 — 조종석·중앙 광장 수직 슬라이스

- 조종석: 스로틀 스탠드·계기 컬럼·항법 테이블은 유지하고, 콘솔 큐브 몸체만 공통 패널 문법으로 교체한다.
- 중앙 광장: 바닥 분할과 방사형 동선만 강조한다. 소품을 늘려 이동 시야를 막지 않는다.
- 관측실: 선수 창이 주인공이므로 프레임 깊이와 좌석 실루엣만 보강하고 별 시야를 가리지 않는다.
- 목표 화면: 입구에서 색만 보지 않아도 세 공간의 기능이 실루엣과 명암 덩어리로 구분된다.

### P2 — 기능실 확장

전력실·냉각실·산소/생명유지실에 같은 구조체 키트를 적용한다. 각 방은 고유 영웅 소품 하나(버스 패널, 냉각 랙, 스크러버/O2 탱크)를 가장 큰 형태로 두고, 나머지는 보조 리듬으로 제한한다. 상태 데칼은 정상 상태 화면의 `5%` 이하 면적에만 쓴다.

### P3 — 화물·격납·정비와 생활공간

큰 방은 랙·크레이트·작업대 반복으로 밀도를 만들되 이동 통로를 먼저 비운다. 생활공간은 공통 구조체 완료 뒤 개인화 소품으로 유쾌한 톤을 강화한다. 이 단계 전까지 신규 소형 장식 대량 제작은 보류한다.

### P4 — 운반 아이템·캐릭터

아이템은 손잡이와 몸통 비례를 과장해 바닥에서도 집을 수 있는 대상으로 읽히게 한다. 캐릭터는 환경 팔레트와 겹치지 않는 명도, 4인 식별색, 저중력 동작 실루엣을 함께 확정한 뒤 별도 제작한다.

## 4. 공통 검수 기준

- `1280×720` 플레이 캡처와 에디터 원경에서 문, 상호작용물, 방 고유색이 서로 겹치지 않는다.
- 무채색 검정 면을 만들지 않고, 저조도 통로도 짙은 청회색의 색감이 남는다.
- 반사보다 면 분할이 먼저 보이며, 글로시한 금속·사실적 오염으로 톤을 무겁게 만들지 않는다.
- 새 구조체는 기존 그레이박스의 통행 폭, 문 높이, 콜라이더 범위를 바꾸지 않는다.
- 한 방의 소형 장식 종류를 늘리기 전에 공통 모듈 재사용률을 확인한다.
- 정상/고장 상태 캡처를 나란히 놓았을 때 상태 데칼과 적색 신호가 정상 화면을 상시 오염시키지 않는다.

## 5. 중요한 트레이드오프와 수동 확인

공통 구조체 키트를 먼저 만들면 한 방만 고급스럽게 만드는 것보다 즉시 보이는 완성도 피크는 낮다. 대신 전 선박의 큐브 인상을 가장 적은 에셋 수로 제거하고, 이후 방별 제작이 같은 조형 언어를 쓰게 된다. 그래서 **키트 제작 → 대표 동선 수직 슬라이스 → 전 구역 확장** 순서를 채택한다.

수동 확인이 필요한 것은 두 가지다.

1. 조종석 입구와 관측실 창 앞의 실제 플레이 카메라에서 챔퍼 폭이 보이는가.
2. 우회 통로의 기존 조도 예산을 유지한 채 검정 덩어리가 아니라 짙은 청회색 공간으로 읽히는가.

이 두 캡처가 통과하기 전에는 전체 구역으로 구조체 키트를 확산하지 않는다.
